# Tasks

> Date: 2026-06-02 · Personal-OS module (step 3). A user-document module (CRUD; the table owns the
> truth). Extends the existing `reminders.py` (time-based nudges) into full to-dos. Inherits the
> shell + module template. First proof that the template scales.

## Shape

- **Migration `0020_tasks`:** `tasks(id, title, notes, status, priority, due_at, completed_at,
  parent_id, source_entity_ref, schema_version, entity_ref, created_at, updated_at)`.
  `status ∈ {open, doing, done, dropped}`; `priority ∈ {low, normal, high}`. `parent_id` →
  subtasks (self-FK, one level). `source_entity_ref` links provenance ("from email:<id>").
  `entity_ref = "task:<id>"`. `ids.TASK` prefix.
- **Relationship to reminders:** a task with a `due_at` **reuses the existing reminder worker** for
  the nudge (a task is the richer object; a reminder is the fire). Either: the reminder worker also
  polls due tasks, or task-create with `due_at` also creates a linked reminder. Pick the smaller
  diff at build time; don't duplicate the polling loop.
- **Model:** `Task` Pydantic (title required/trimmed; due_at validated; status/priority enums).
- **Tools** (`tasks.*`, all **auto-run** — reversible, low-risk, on-box): `task.create`,
  `task.update` (status/priority/due/title/notes), `task.complete`, `task.delete`. Contracts:
  `side_effects=false` (stays on box), `rollback=manual` (a delete is undoable by recreate; keep
  soft-delete = `status=dropped` rather than hard delete for audit).
- **Awareness events:** `task.created`, `task.completed`, `task.due_soon` (from the worker).
  `info`; carry `entity_ref` + `correlation_id`.
- **Search:** index `title`+`notes` via the shared hook (`source=tasks`).
- **Context:** `open_tasks(limit)` / `due_today()` for the conversation agent + the daily brief.

## Cross-module + AI

- **"turn this into a task"** from email/note/chat: a `task.create` with `source_entity_ref` set →
  linking rides `entity_ref`. The conversation agent already routes intents; add `task.*` to its
  capability summary.
- **Daily brief:** `due_today()` feeds the morning push (extends routines/ntfy).
- **Voice:** "add milk to the list", "what's due today", "mark the rent task done".

## Frontend

Route `/tasks` + nav entry + panel (list grouped by status/due, quick-add, complete checkbox,
priority/due edit, subtasks). Cmd-K provider (search open tasks, quick-add). Theme tokens.

## Testing → acceptance

- **Unit:** `Task` validation; each tool (create/update/complete/delete) + grading = auto-run;
  awareness events emitted; due→reminder linkage; search indexing (mock embedder).
- **Integration (auto-skip):** CRUD round-trip; `due_soon` fires through the notifier; "from email"
  provenance link resolves.
- **Frontend (vitest):** panel renders/groups; quick-add; complete; Cmd-K provider.
- **Gate:** CRUD + auto-run tools + events + search + panel; "remind me / turn into task" works;
  daily brief shows due tasks; suite + lint green.
