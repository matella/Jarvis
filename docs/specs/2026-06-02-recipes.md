# Recipes

> Date: 2026-06-02 · Personal-OS module (step 5). A user-document module (CRUD; the table owns the
> truth), notes-flavored + a one-shot **URL→structured import**. Shows off cross-module flow:
> recipe → shopping list → tasks. Inherits the foundation + shell template.

## Shape

- **Migration `0023_recipes`:** `recipes(id, title, source_url, servings, ingredients_json,
  steps_json, tags, notes_md, schema_version, entity_ref, created_at, updated_at)`.
  `ingredients_json` = `[{name, quantity, unit}]`; `steps_json` = `[str]`. `entity_ref =
  "recipe:<id>"`. `ids.RECIPE` prefix.
- **Model:** `Recipe` Pydantic (title required; ingredients/steps validated as typed lists; tags
  normalized).
- **Tools** (`recipe.*`, **auto-run** — reversible/low-risk/on-box): `recipe.create`,
  `recipe.update`, `recipe.delete` (soft). `side_effects=false`, `rollback=manual`.
- **URL import** = **one bounded operation** (Hard Rule #2): `recipe.import_url` —
  fetch (egress-guarded + sanitized + wrap_untrusted) → **one** grammar-constrained inference
  (local) → structured `Recipe` proposal → validated → `recipe.create`. The fetch is deterministic;
  the parse is one one-shot call; the model proposes, deterministic create applies. **Gated only if
  egress to an arbitrary URL needs it** — but since it's read-only fetch of a user-supplied URL via
  the existing egress allowlist+sanitize, treat the *import* as auto-run if the URL passes egress,
  else surfaced for confirm. (Reuses the same web-fetch discipline as search.)
- **Awareness events:** `recipe.created`, `recipe.imported` (`info`; `entity_ref` + `correlation_id`).
- **Search:** index `title`+ingredients+`notes_md` via the shared hook (`source=recipes`).
- **Context:** `search_recipes` for the conversation agent ("what can I make with chicken?").

## Cross-module + AI (the payoff)

- **"recipe → shopping list → tasks":** `recipe.to_shopping_list` → for each ingredient not on hand,
  a `task.create` (or a single grouped task) → linked by `source_entity_ref=recipe:<id>`. Pure
  cross-module wiring; no new data class.
- **"scale this recipe to 6 servings"** = one inference recompute (proposal) or deterministic
  quantity math (prefer deterministic — multiply; no LLM needed).
- **Voice:** "import this recipe <url>", "add the ingredients for <recipe> to my list".

## Frontend

Route `/recipes` + nav + panel (card grid, import-by-URL box, ingredient/step editor, servings
scaler, "add to shopping list" button). Cmd-K: "find a recipe with …", "import recipe". Theme tokens.

## Testing → acceptance

- **Unit:** `Recipe` validation (ingredient/step typing); CRUD tools + grading; `import_url` with a
  **mocked** fetch+scheduler → structured proposal validated → create (no real web/LLM); deterministic
  serving-scale math; search indexing.
- **Integration (auto-skip):** import a real recipe URL → structured recipe; "to shopping list"
  creates linked tasks.
- **Frontend (vitest):** card grid, import box, editor, scaler, "add to list".
- **Gate:** manual CRUD + URL import (one inference) + recipe→tasks cross-module; suite + lint green.
