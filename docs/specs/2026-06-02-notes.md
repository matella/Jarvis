# Notes

> Date: 2026-06-02 · Personal-OS module (step 3). A user-document module (CRUD; the table owns the
> truth). Markdown jottings — lighter than Documents (no AI co-write harness), heavier than a fact.
> Extends the existing memory/KB retrieval. Inherits the shell + module template.

## Shape

- **Migration `0021_notes`:** `notes(id, title, body_md, pinned, archived, tags, source_entity_ref,
  schema_version, entity_ref, created_at, updated_at)`. `body_md` = markdown text. `tags` = text[]
  (light, not a taxonomy). `entity_ref = "note:<id>"`. `ids.NOTE` prefix.
- **Notes vs Facts vs Documents:** **Facts** (`user_facts`) = atomic operator truths Jarvis recalls
  ("city = Brussels"). **Notes** = freeform markdown the operator/Jarvis jots and finds later.
  **Documents** (separate module) = long-form, AI co-written, versioned. Notes do **not** get the
  co-write harness; promoting a note → document is a cross-module action.
- **Model:** `Note` Pydantic (title optional → derived from first line; `body_md` trimmed; tags
  normalized lower).
- **Tools** (`note.*`, **auto-run** — reversible/low-risk/on-box): `note.create`, `note.update`,
  `note.delete` (soft = `archived=true`; hard-delete gated? no — archive is enough, keep auto-run).
  `side_effects=false`, `rollback=manual`.
- **Awareness events:** `note.created`, `note.updated` (`info`; `entity_ref` + `correlation_id`).
  Resist a `note.viewed` event (low signal — foundation's "resist low-signal events").
- **Search:** index `title`+`body_md` via the shared hook (`source=notes`) — this is the primary way
  notes are recalled; reuse the existing KB-ingest/memory retrieval verbatim.
- **Context:** `search_notes(query)` / `recent_notes(limit)` for the conversation agent.

## Cross-module + AI

- **"save that as a note"** / **"research X → save as a note"** (deep-research output can land as a
  note **or** a document — note for short, document for long). **"note → task"**, **"note →
  document"** (promote). All ride `entity_ref` linking.
- **Voice:** "make a note: …", "find my note about …".

## Frontend

Route `/notes` + nav + panel (list/grid, pin, tag filter, markdown editor with live preview — reuse
the same markdown editor component as Documents to avoid two editors). Cmd-K provider (full-text +
quick-create). Theme tokens.

## Testing → acceptance

- **Unit:** `Note` validation (title derivation, tag normalize); tools + grading = auto-run; events;
  search indexing + recall (mock embedder).
- **Integration:** CRUD round-trip; search recall returns a created note; "note → task"/"note →
  document" links resolve.
- **Frontend (vitest):** panel, markdown preview, pin/tag filter, Cmd-K.
- **Gate:** CRUD + auto-run + events + search + panel; recall via Cmd-K and via chat works; suite +
  lint green.
